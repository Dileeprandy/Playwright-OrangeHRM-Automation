# AccuKnox User Management Automation

This repository contains the automated End-to-End (E2E) UI test suite for the OrangeHRM User Management module, created as part of the AccuKnox QA Trainee practical assessment.

## Framework Details
*Language:* Python
*Tool:* Playwright (pytest-playwright)
*Design Pattern:* Page Object Model (POM)
*Playwright Version:* 1.44.0 (or current installed version)
